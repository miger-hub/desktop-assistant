# 国际化（i18n）

本项目支持三种界面语言，主进程与渲染进程共用同一套文案：

| locale | 名称 | 说明 |
| --- | --- | --- |
| `zh-CN` | 简体中文 | 默认语言，也是缺键时的兜底语言 |
| `zh-TW` | 繁體中文 | 台湾用语（檔案 / 資料夾 / 儲存 / 剪貼簿 / 系統匣…） |
| `en` | English | 美式英语 |

## 目录结构

```text
src/shared/i18n/
  index.ts               纯逻辑：locale 类型、语言解析、文案查找与占位符替换
  messages/zh-CN.ts      语言包
  messages/zh-TW.ts
  messages/en.ts
src/main/i18n.ts         主进程运行时：t() / applyLanguageSetting()
src/renderer/i18n/index.ts  渲染进程运行时：响应式 t() / setLocale()
```

`src/shared/i18n` 不依赖 Vue / Electron，可以单独测试；主进程和渲染进程各自包一层运行时。

## 语言设置

- 设置项是 `AppSettings.language`，取值 `'system' | 'zh-CN' | 'zh-TW' | 'en'`，默认 `'system'`。
- `'system'` 时：渲染进程用 `navigator.language`，主进程用 `app.getLocale()`，都通过
  `resolveLocale()` 落到受支持的语言（`zh-Hant*` / `zh-TW` / `zh-HK` / `zh-MO` → `zh-TW`，
  其它 `zh*` → `zh-CN`，`en*` → `en`，其余回退默认语言）。
- 切换语言后：
  - 渲染进程 `t()` 读取的是响应式 locale，用到它的组件会自动重渲染；
  - Vuetify 内置文案通过 `applyVuetifyLocale()` 切到对应的 Vuetify locale；
  - 主进程通过 `applyLanguageSetting()` 切换，托盘菜单 / 提示会重建；
  - `document.documentElement.lang` 同步更新。

## 文案 key 约定

文案按「区域.用途」分组（嵌套对象，取用时用点号路径）。常用的分组：

- `common.*`：确定 / 取消 / 保存 / 删除…等通用词
- `nav.*`：侧边栏菜单名
- `error.*`：渲染进程统一兜底提示（`ui.handleError` 的 fallback）
- `toast.*`：成功 / 提示类 toast
- `svc.*`：主进程抛出的错误（文件 / 工作区 / 待办 / 备忘 / 规则 / 设置…）
- `settings.*`、`search.*`、`file.*`、`workspace.*`、`todo.*`、`notes.*`、`clipboard.*`、`rules.*`：对应页面

规则：

1. key 只描述用途，不要塞具体文案（用 `settings.confirmDelete`，而不是 `settings.deleteBeforeDelete`）。
2. 带变量的文案用 `{name}` 占位符，调用时传参：`t('toast.undone', { count: 3 })`。
3. 新增文案必须三种语言都补齐；缺键会回退默认语言，再缺会直接显示 key，方便一眼看出漏翻。
4. 不要把中文拼一半再翻译，尽量整句放进语言包，语序差异交给各语言自己处理。

## 翻译风格

译文要贴合各语言习惯，而不是逐字直译：

- 简体（zh-CN）：中国大陆常用词（文件夹 / 目录 / 剪贴板 / 默认 / 回收站 / 设置 / 搜索）。
- 繁体（zh-TW）：台湾常用词与标点——檔案（不是「文件」）、資料夾、儲存（不是「保存」）、
  開啟、關閉、搜尋、剪貼簿、系統匣（tray）、快速鍵（shortcut）、備份、資料庫、目錄、字元、
  連結（link）、資源回收筒（trash）、資料（data）、預設（default）、設定（settings）；
  用全角标点，量词优先用「筆 / 項 / 則」。
- 英文（en）：美式英语，简洁、动词开头；避免直译出来的中式英语。

品牌名 `Desktop Assistant` 不翻译。

## 使用方法

渲染进程（组件 / store / composable）：

```ts
import { t } from '../i18n'

ui.toast(t('toast.copiedClipboard'), 'success')
ui.toast(t('workspace.created', { name: workspace.name }), 'success')
```

模板里直接用 `t()`（会跟随语言变化自动刷新）：

```vue
<span>{{ t('nav.workspace') }}</span>
```

需要跟随语言变化的数组 / 常量写成 `computed`，不要写成模块级常量（那样只会在首次求值时固定下来）。

主进程：

```ts
import { t } from '../i18n'

throw notFound(t('svc.notExist', { what: t('svc.dir'), value: resolved }))
```

## 边界与注意

- IPC 只能传纯数据：带数组设置（如 `openWithRules`）时先把 Vue 响应式对象拍平成普通对象再传，
  否则结构化克隆会报 "an object could not be cloned"。
- 数据库里的内容（工作区名、待办标题、备忘正文等）是用户数据，不翻译。
- 日志（`console.*`）与代码注释保持中文，便于维护，不属于界面文案。
- 新增语言：在 `Locale`、`LOCALES`、`MESSAGES` 里加一项，补一份语言包；设置页的语言下拉按
  `LOCALES` 顺序自动出现。

## 测试

`tests/i18n.test.ts` 会校验三种语言 key 完全一致、没有空文案、语言解析与占位符替换正确。
改语言包时漏了一条，这个测试会直接失败。
